# FinalProject
**Bean there, done that**
Current methods for barista training can feel boring, repetitive, and hard to follow, especially for new hires with little experience. Traditional training methods often rely on manual or verbal instruction, or passive observation, which may not effectively prepare employees for fast-paced environments. Bean There, Done That is a VR Barista Training application that provides an immersive, hands-on learning experience, allowing trainees to actively engage with tools, ingredients, and the drink-making process in a safe, simulated environment. By following specific recipes step by step in virtual reality, new employees can build confidence, accuracy, and speed before handling real equipment or serving customers
